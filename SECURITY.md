# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 1.x.x   | :white_check_mark: |
| < 1.0   | :x:       |

## Reporting a Vulnerability

We take the security of Myko AI seriously. If you discover a security vulnerability, please report it privately.

* **Where to report:** Open a private security advisory on GitHub or contact the maintainer.
* **What to include:** Provide a description, steps to reproduce, and potential impact.
